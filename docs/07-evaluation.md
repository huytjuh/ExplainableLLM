# Evaluation and LLM-as-a-Judge

Evaluation should measure both retrieval and generation.

Useful dimensions:

- correctness,
- groundedness,
- relevance,
- completeness,
- citation quality,
- latency,
- cost.

LLM-as-a-judge systems should use clear rubrics, fixed output schemas, and regression datasets. Human review is still needed for high-stakes decisions.
