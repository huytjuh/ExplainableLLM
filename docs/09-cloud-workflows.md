# Cloud Workflows

Cloud workflows connect development, evaluation, and deployment.

Planned integrations:

- Gemini 2.5 Flash Lite API for fast generation.
- Vertex AI for Google Cloud model and ML workflows.
- Azure DevOps for CI/CD.
- Pipeline artifacts for traces, reports, and evaluation outputs.

Secrets such as API keys should be stored in CI/CD secret variables, not committed to source control.
