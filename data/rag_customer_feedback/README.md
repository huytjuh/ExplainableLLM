# Synthetic Customer Feedback Corpus

This folder contains synthetic bilingual customer-feedback documents for RAG experiments.

- Language coverage: English and Dutch.
- Format: plain text files.
- Domain: ecommerce customer support, delivery, billing, product quality, app experience, loyalty, and returns.
- Use case: test document loading, chunking, embeddings, vector search, retrieval, and answer generation.

Suggested test questions:

- What are the main reasons customers are unhappy with deliveries?
- Welke problemen noemen Nederlandse klanten over retourzendingen?
- Which feedback mentions billing or refunds?
- Wat vinden klanten van de mobiele app?
- Summarize positive feedback about support agents.
